# Circle navigation: four doors on top, programmes in the sidebar

From the design handoff of 17 Oct 2026 (Today · Calendar · Practice · Library, and the four programmes Meditation Mondays · Wisdom School · Sādhana School · Sahṛdaya Upāya).

## Built so far
**Phase 1, preview pages (lock screens):** `/programmes/{meditation-mondays|wisdom-school|sadhana-school|sahrdaya-upaya}/preview`. Text is in `data/programmes.json`: title, a paragraph, what is included, one public sample and one button. The first draft was written from the site's own landing pages (`/meditation-pass`, `/wisdom-school`, `/sadhana-school`, `/sahrdaya-upaya`); staff can change any of it by editing that file. No prices, and nothing is read from a private space. Buttons open in the full window (`target="_top"`).

**Today (`/c/today`):** built. One page for every signed-in member (`public/circle/today.js`, data from `/api/member/today`, `lib/member/today.js`). Top half: the free practice layer (today's sit and timer, streak and mālā, the teaching of the week and a question). Below: one card per programme the member is in, then one locked card per programme they aren't (link to its preview page), then one suggestion at most. Layout: main column, a 270px right rail (Coming up, Sacred days ahead, Practising with you) and a full-width pañcāṅga band at the bottom; under 760px wide (a container query on the page, not the window) it stacks, with the pañcāṅga after the teaching. Which programmes open for which membership is `OPEN` in `lib/member/programmes.js`. The weekly teaching is edited in Ops → Settings → Website → "Today: teaching" (sheet tab `Site Teachings`, fallback `data/teachings.json`); the sacred days are the "Site Sacred Days" tab (fallback `data/sacred-days.json`). Circle's own space banner ("Today in School", member avatars, New post) is hidden on this page, and the pañcāṅga band (docs/panchanga.md) is native. **How it loads fast:** the moment `/c/today` opens, Circle's own page is hidden by CSS and a placeholder of the real layout is drawn, so nothing underneath shows through; `/api/member/today` then signs the student in (Circle's identity token in `X-Circle-Identity`) and returns everything in one call, with every part fetched in parallel on the server (its `Server-Timing` header shows where the time went: browser dev tools → Network → the `today` call → Timing). The other Circle page scripts (CE, Portfolio, Schedule, My Practice, Library, This week) now load when their page is opened and are fetched quietly once Today is showing. Leaving Today gives Circle's page back. The Home feed is unchanged (the old practice strip is gone). Practice circles and a Calendar door don't exist yet, so those links are left out.
